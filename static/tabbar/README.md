# TabBar 图标说明

## 需要的图标文件

请将以下 10 个 PNG 图标文件放置在此目录：

### 首页
- `home.png` - 首页图标（未选中）
- `home-active.png` - 首页图标（选中）

### 互助
- `mutual.png` - 互助图标（未选中）
- `mutual-active.png` - 互助图标（选中）

### 发布
- `post.png` - 发布图标（未选中）
- `post-active.png` - 发布图标（选中）

### 消息
- `message.png` - 消息图标（未选中）
- `message-active.png` - 消息图标（选中）

### 我的
- `profile.png` - 我的图标（未选中）
- `profile-active.png` - 我的图标（选中）

## 图标规格要求

- **尺寸**：81px × 81px（推荐）
- **格式**：PNG
- **颜色**：
  - 未选中状态：#999999
  - 选中状态：#1890ff
- **背景**：透明
